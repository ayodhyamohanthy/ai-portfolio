# Ayodhya portfolio coded build

## Product direction
Recruiter-first portfolio that demonstrates startup range through real work: B2B/SaaS application automation, healthcare operations, data-informed product design, industrial telemetry, and ad-platform workflows. E-commerce is not claimed without a real case.

## Experience direction
The site itself should feel AI-native without a chatbot cliché. Use an evidence lens: visitors can change what they optimize for (startup founder, design lead, recruiter) and the same verified case evidence reorders or annotates itself. AI remains an explicit collaborator; Ayodhya owns source checks, tradeoffs, direction, and accountability.

## Design system
Editorial off-white #F7F4EE base, black #111111, acid lime #C6FF58 accent, purple #7C6AF2 secondary. Google Sans/clean grotesk direction. Strong type hierarchy, bordered modules, tight radii, no decorative gradients. Motion: restrained reveal timing, filter/reorder transitions, pointer/focus detail, and full prefers-reduced-motion support.
