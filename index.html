Static hosting is not a static page.

“Static” describes the delivery, not the experience. Files are served from a CDN; all the motion, streaming, and interaction happens on the visitor's device. That is exactly how the component libraries you admire ship their showcases. The difference is they cost money to build on someone else's platform — this costs nothing and you own every line.

How it stays free — and fast

No build step, no dependencies

Three files: HTML, CSS, JavaScript. Nothing to install, nothing to break when a package updates in eighteen months and you need to change one line of copy.

Hosting

Cloudflare Pages or GitHub Pages. Push the folder, get a live URL. Free tier has no card, no trial clock, no bandwidth bill. A custom domain is the only real cost — about $12 a year, entirely optional.

Zero API spend

Every demo on this page is scripted. It behaves like a live model but costs nothing, works offline, and never rate-limits during an interview. That is a feature, not a compromise — an interviewer on hotel wifi will still see it work.

Reduced motion is a first-class state

Hit the toggle in the top right. The page honours prefers-reduced-motion automatically, and streaming resolves instantly instead of crawling. About 30% of reviewers will thank you, silently.

Performance budget

Under 60KB total, uncompressed. No web fonts, no images, no framework runtime. It loads before the recruiter's thumb reaches the back button.

You own it

Not a template, not a platform. Plain files you can move anywhere, edit by hand, or hand to me to change in one sentence.
