Every component here is a design argument.

A portfolio that says "I designed AI features" is a claim. A portfolio where the reviewer can drag an autonomy dial and watch the interface renegotiate control is evidence. Each primitive below encodes a decision I'd defend in a critique — and the note under every one says why.

01

Loading state

Pixel-grid loader with shimmer and elapsed time

Churning0.0s

Past ~800ms a spinner becomes a suspicion that it broke. An elapsed clock turns waiting into progress, and the verbs tell you what it's doing — not just that it's busy.

The composer is the product. @ and / turn prompting from a blank page into a menu, and a visible model picker makes the speed/quality trade the user's call rather than yours.

Fine-tune card

The agent adjusts properties in an inspector

Free cone FridayPistachio · this week only

Don't let the agent rewrite the artefact — let it move the sliders. The user sees what changed, can reverse any single value, and learns the design system by watching it.

20

Selection actions

Highlight a passage, hand it to the agent

The refund window is thirty days from delivery. Items damaged in transit are exempt from the restocking fee. Select any of this text to see the agent actions appear.

Bring the agent to the object instead of the object to the agent. No copy-paste, no lost context, and the action set adapts to what was selected.

How this stays free and fast

No build step, no dependencies

Three files: HTML, CSS, JavaScript. Nothing to install, nothing to break when a package updates in eighteen months and you need to change one line of copy.

Hosting

GitHub Pages. Push the folder, get a live URL. No card, no trial clock, no bandwidth bill. A custom domain is the only real cost — around ₹800 a year, entirely optional.

Zero API spend

Every demo is scripted. It behaves like a live model but costs nothing, works offline, and never rate-limits mid-interview. That's a feature: an interviewer on hotel wifi still sees it work.

Reduced motion is a first-class state

Toggle it in the top right. The page honours prefers-reduced-motion automatically and streaming resolves instantly instead of crawling.

Performance budget

Under 120KB uncompressed. No web fonts, no images, no framework runtime. It loads before a recruiter's thumb reaches the back button.

You own it

Not a template, not a platform. Plain files you can move anywhere, edit by hand, or hand over to be changed in one sentence.
